## Conventions Used in These Docs

- **Lane 1** — real filterbank / spectrogram OOD pathway. Signals featurised by a
  single deterministic map (`axiom.dsp.waterfall.extract_features`, 12-D) and scored
  by per-class conformal detectors; real observations additionally scored by native
  frequency-resolved descriptors (`axiom.dsp.waterfall_features`).
- **Lane 2** — population-scale catalog manifold. Thousands of independent objects
  (ATNF, CHIME/FRB, HTRU2) featurised by `axiom.dsp.physical_features` (12-D) and
  evaluated with leakage-free group cross-validation.
- **HTRU2 manifold** — the 8 survey moments used by the in-distribution production
  classifier (`AxiomEnsemble` + `AnomalyDensityEstimator`).
- **OOD** — Out-Of-Distribution: a signal lying outside the learned natural manifold.
- **Conformal p-value** — distribution-free, finite-sample-valid probability under the
  null (natural) population; `p < α` ⇒ flag.
- **"Anomaly" ≠ proof of artificial origin** — it is a statistical off-manifold verdict
  requiring human review (see [`../README.md`](../README.md) §07).

## How the Documentation Is Kept Honest

Every figure and table in `benchmarks/` is regenerated by
`scripts/generate_reports.py` (`make report`) from the live codebase and cached real
catalogs. The documents here describe *method*, not *results*; results live in
`benchmarks/reports/` and `BENCHMARKS.md` and are the single source of truth for
empirical claims.
